3 / 13
how

Four rules

1
Never guess silently. Unreadable or ambiguous → NA + warning with the count.
2
Report every change. Changed place names are listed; typing-error fixes are marked as guesses.
3
One in, one out. Same length and order; tables keep the input in column 1.
4
Bangla everywhere. Digits, names, units and Unicode variants of the same letters.

bd_phone()

  1. remove spaces, dashes, dots, brackets, quotes, invisible characters
  2. read Bangla digits; accept +880, 00880, 880, missing 0
  3. valid = 10 digits starting 13–19
  4. several numbers? split at / , ; & | or
  5. multiple = "na": do not choose; "first": choose the first

thanas

Thanas only, below the district

A rural thana has the same name and area as its upazila, so one level is enough: upazila names are read as thana names (“Savar Upazila” → Savar).

  • rural — 503
  • city — Mirpur, Double Mooring … (61)
  • within — Ashulia in Savar, Tongi in Gazipur Sadar … (6)

Same name, several districts: Kaliganj (4), Kotwali, Mirpur… → give district, otherwise ambiguous. “Sadar” needs the district. style = "map" gives boundary-file names.

Demonstration data

3,030 rows (3,000 records + 30 duplicates), 10 columns, every column messy; an answer key with the true value of every cell and how it was written.

  • phones: +880, dashes, dropped 0, Bangla, apostrophe, two per cell, +881, short, 012, E+09, .0, N/A
  • income: Tk, BDT, /-, k, lakh, hajar, Bangla, per month, ranges, about, wrong commas, unknown
  • places: old, Bangla, suffixes, variants, map spellings, one-letter typos, blanks
  • addresses: 7 templates, with/without P.O. and post code; rural, city and “within” thanas
